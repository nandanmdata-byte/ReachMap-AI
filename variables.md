# Information about the initiating variables in capture.py



| Variable | Purpose |
|---|---|
| pending_zone	| Zone currently being considered |
| pending_start |	Time when the pending zone was first observed |
| stable_zone	  | Most recently confirmed zone |
| last_seen     |	Time of last valid hand observation |
| visits	      | Total confirmed zone visits |
| interaction_count	 | Number of confirmed possible-interaction events |
| last_timestamp_ms	| Previous timestamp supplied to MediaPipe |
| overlap_start	| When fingertip overlap began for an object class |
| overlap_last	| Most recent overlap time for each class |
| active_interactions	| Object classes with currently confirmed interaction events |
| reference_size	| Calibrated apparent palm size |
